# Duel update implementation

Authorized by the user's acceptance of the lead design, 2 November 2026. Finish this bounded slice before expanding the backlog.

1. Versioned `duel_v2` default and selectable `classic_v1`: complete two-round role pairs, draw on timeout, shared rear-lethal/front-interrupt knife rules.
2. Three-shot rifle magazine, finite reserve, committed audible reload, own-resource HUD and bot reload decisions.
3. Three physical pebble distractions per stalker, anonymous approximate sound and bird reactions, host authority and replay reconstruction.
4. Short completed-round evidence review, quick rematch, clear role/control guidance, self-noise feedback derived only from own movement.
5. Versioned forest sightline/position refinements if the audit identifies a concrete improvement; preserve legacy replay terrain. Test actual traversal.
6. Source regression, two-peer tests, bounded bot cohort and a current recording, native Windows export/runtime and local release archives.

Keep the existing slate, chalk and amber interface, Display/Body fonts and split POV composition. Ammunition belongs beside weapon readiness; pebble count/control beside stalker equipment; round review uses a short factual clue list with immediate rematch access. No unrelated visual redesign.

No automatic player reveals, hidden proximity contests, live detection guarantees or hidden opponent data in bot decisions. Relay objectives remain conditional on human findings and are not part of this slice. Existing recordings and delivered movie remain intact. A baseline source archive is in `artifacts/design-slice/baseline`.
